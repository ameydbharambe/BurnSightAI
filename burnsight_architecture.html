BurnSight AI Architecture

AI-powered burn classification & first-aid chat assistant — Streamlit + FastAPI + PyTorch + Gemini

Frontend & Client

  • • Streamlit web app (app.py)
  • • Session identity via UUID in URL query param
  • • Local JSON chat history, per session
  • • History files auto-purged after 24 hours

Backend & ML

  • • FastAPI REST API (main.py), CORS enabled
  • • PyTorch ResNet-50 + fine-tuned classifier head
  • • Global in-memory model + chat instances (shared)
  • • Base weights pulled from Hugging Face at cold start

LLM & External Services

  • • Google Gemini 2.5 Flash for diagnosis + follow-up chat
  • • Google Search grounding tool (auto-invoked)
  • • Stateful multi-turn chat session, per backend process
  • • No database — file-based persistence only
